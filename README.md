# Shelf

복사한 내용을 쌓아두고 다시 꺼내 쓰는 macOS 메뉴 바 앱입니다.
텍스트와 이미지, 파일을 모두 기억하며, 목록에서 클릭하면 클립보드로 되돌리고
끌어내면 다른 앱에 진짜 파일로 떨어집니다. 모든 데이터는 이 맥 안에만 저장되며
서버와 통신하지 않습니다.

## 설치

macOS 14 이상이 필요하며, 애플 실리콘과 인텔 맥을 모두 지원합니다.
Xcode는 필요하지 않고 Command Line Tools만 있으면 됩니다.

```bash
xcode-select --install     # 이미 설치되어 있다면 건너뜁니다
gh repo clone seenew22/Shelf
cd Shelf
./build.sh --run
```

이 저장소는 비공개라서 처음 쓰는 맥에서는 `gh auth login` 으로 한 번 로그인해 두어야
합니다. 인증 방법과 대안은 [INSTALL.md](INSTALL.md) 에 정리해 두었습니다.

메뉴 바 오른쪽에 트레이 모양 아이콘이 나타나면 성공입니다. Dock에는 아이콘이 생기지
않습니다.

다른 맥으로 앱을 옮기는 방법, 로그인할 때 자동 실행하는 방법, 문제가 생겼을 때의
대처는 **[INSTALL.md](INSTALL.md)** 에 정리해 두었습니다.

## 빌드 옵션

```bash
./build.sh                # 이 맥의 구조에 맞춰 릴리스로 빌드합니다
./build.sh --run          # 빌드한 뒤 바로 실행합니다
./build.sh --debug        # 디버그 구성으로 빌드합니다
./build.sh --universal    # 애플 실리콘과 인텔 양쪽에서 도는 앱을 만듭니다
```

옵션은 함께 쓸 수 있습니다. 다른 맥에 넘겨줄 앱을 만들 때는 `--universal` 을 붙이면
받는 쪽의 구조를 신경 쓰지 않아도 됩니다.

## 사용법

| 동작 | 방법 |
| --- | --- |
| 히스토리 열기 | `⌘⇧V` (마우스 커서 옆에 열립니다) 또는 메뉴 바 아이콘 클릭 |
| 항목 고르기 | `↑` `↓` 또는 마우스 올리기 (키보드로 옮길 때만 목록이 따라 움직입니다) |
| 항목 다시 복사 | `⏎` 또는 항목 클릭 (`복사됨` 표시 후 창이 닫힙니다) |
| 다른 앱으로 보내기 | 항목을 잡아서 Finder, Slack, Figma 등으로 끌어다 놓기 |
| 항목 위에 고정 | 항목 위에 마우스를 올린 뒤 압정 버튼 클릭 |
| Finder에서 보기 | 항목을 오른쪽 클릭, 또는 고른 뒤 `⌘⏎` |
| 기본 앱으로 열기 | 항목을 오른쪽 클릭 → `열기` |
| 항목 하나 삭제 | 항목 위에 마우스를 올린 뒤 오른쪽의 × 버튼 클릭 |
| 전체 삭제 | 아래쪽 `모두 지우기` (고정한 항목은 남습니다) |
| Finder 열기 | 오른쪽 위 폴더 버튼 |
| 설정 열기 | 오른쪽 위 톱니바퀴 버튼 (가장자리 열기, 나타나는 방식, 언어, 버전) |
| 창 닫기 | `Esc`, 또는 창 바깥 클릭 |

`⌘⇧V` 로 열면 창이 화면 위쪽이 아니라 **마우스 커서 옆에** 나타납니다. 그대로
`↓` 로 원하는 항목까지 내려간 뒤 `⏎` 를 누르면 마우스에 손을 대지 않고 끝납니다.

## 자주 쓰는 항목 고정하기

폴더나 파일을 복사해 두고 계속 다시 여는 경우가 있습니다. 그런데 히스토리는 새로
복사할 때마다 밀려 내려가서 결국 50개 제한에 걸려 사라집니다.

항목에 마우스를 올렸을 때 나오는 **압정 버튼**을 누르면 그 항목이 목록 맨 위에
붙박입니다. 고정한 항목은 **개수 제한에서 아예 빠지므로** 아무리 많이 복사해도
밀려나지 않고, `모두 지우기` 를 눌러도 남습니다. 사실상 자주 쓰는 폴더의 바로가기
목록이 됩니다.

폴더 항목을 오른쪽 클릭하면 `Finder에서 보기` 와 `열기` 가 나옵니다.
`Finder에서 보기` 는 보관용 복사본이 아니라 **원래 있던 자리**를 보여 줍니다.
목록에서 항목을 고른 뒤 `⌘⏎` 를 눌러도 같습니다.

## 나타나는 방식

창이 나타날 때의 움직임을 네 가지 중에서 고를 수 있습니다. 오른쪽 위 톱니바퀴 →
`나타나는 방식` 에 있습니다.

| 이름 | 느낌 |
| --- | --- |
| `물방울` (기본값) | 작은 방울이 부풀어 오르듯 모서리가 펴지면서 커집니다 |
| `서랍` | 서랍을 빼내듯 한 방향으로 곧게 펼쳐집니다. 튀지 않고 차분합니다 |
| `팝` | 작은 크기에서 힘차게 튀어나옵니다. 가장 빠릅니다 |
| `잔잔하게` | 거의 움직이지 않고 조용히 나타납니다 |

네 방식은 크기 변화뿐 아니라 **도착하는 순간의 몸짓**이 다릅니다.

- `팝` 은 6도 비스듬히 나타났다가 바로 서면서 세로로 늘어나고, 목록이 위에서부터
  하나씩 차례로 차오릅니다.
- `물방울` 은 젤리처럼 옆으로 퍼졌다가 되돌아오고, 목록이 빠르게 이어서 차오릅니다.
- `서랍` 은 몸짓 없이 곧게 서고, `잔잔하게` 는 아무 몸짓도 하지 않습니다.

화면 가장자리에서 잡아 뺄 때도 마찬가지입니다. 내밀어 두는 폭, 손을 따라 나오는 정도,
제자리에 닿는 순간의 몸짓이 모두 다릅니다.

## 화면 가장자리로 열기

화면 왼쪽이나 오른쪽 끝에 마우스를 잠시 대고 있으면 선반이 나타나게 할 수 있습니다.
처음에는 **꺼져 있습니다.** 화면 끝을 스치기만 해도 창이 뜨면 거슬릴 수 있어서,
원하실 때 직접 켜도록 두었습니다.

오른쪽 위 톱니바퀴 → `화면 가장자리로 열기` 에서 `왼쪽` / `오른쪽` / `양쪽` 중에
고르시면 됩니다.

화면 끝에 마우스를 잠깐 대고 있으면 **선반의 가장자리가 화면 안으로 조금 나옵니다.**
별도의 손잡이가 아니라 선반 자체의 끝이므로, 잡아당기는 대상과 나오는 물건이 같습니다.

- 마우스를 **안쪽으로 잡아당기면** 선반이 따라 나옵니다. 당기는 만큼 실제로 딸려 나오고,
  충분히 당기면 툭 하고 제자리에 섭니다.
- 잡아당기지 않고 **그대로 대고 있어도** 잠시 뒤에 저절로 나옵니다.
- 도중에 그만두면 화면 밖으로 도로 들어갑니다.

감지는 화면 가장자리 **전체가 아니라 세로 한가운데 절반**에서만 이루어집니다.
브라우저의 뒤로 가기 버튼이나 사이드바처럼 화면 왼쪽 위에는 마우스가 자주 가고,
아래쪽 모서리는 마우스를 치워 두는 자리이자 macOS 핫코너가 쓰는 자리이기 때문입니다.
창을 끌어다 화면 끝에 붙이는 중에도 반응하지 않습니다.

다 나온 창은 마우스가 한참 멀어진 상태가 이어져야 스스로 닫힙니다. 잠깐 벗어났다고
바로 사라지지는 않습니다. 항목을 끌고 있는 동안에도 닫히지 않으므로 다른 앱으로
드래그하는 데 지장이 없습니다.

모니터를 여러 대 쓰는 경우, **다른 화면과 맞닿은 안쪽 경계에서는 열리지 않습니다.**
그런 경계는 마우스가 화면을 오갈 때 통과하는 통로라서, 거기서 선반이 뜨면 방해만
되기 때문입니다. 바깥쪽으로 더 이상 화면이 없는 진짜 끝에서만 반응합니다.

## 언어

오른쪽 위 지구본 버튼에서 표시 언어를 고를 수 있습니다. 기본값은 `시스템 설정 따름`
이며, 한국어와 영어 중 하나로 고정할 수도 있습니다. 고른 값은 다음 실행에도 유지됩니다.
목록에 담긴 내용 자체는 복사한 그대로 보여 주며, 번역하지 않습니다.

언어를 추가하려면 세 군데만 손보면 됩니다.

1. `Resources/<언어 코드>.lproj/Localizable.strings` 를 만들고 기존 파일의 키를 그대로 번역합니다.
2. `AppLanguage` 열거형에 항목을 추가하고 `menuTitle` 에 그 언어로 된 이름을 적습니다.
3. `Resources/Info.plist` 의 `CFBundleLocalizations` 에 언어 코드를 넣습니다.

빌드 스크립트가 `Resources/*.lproj` 를 통째로 번들에 넣기 때문에 그 외의 작업은 없습니다.

## 동작 방식

- **클립보드 감지**: macOS에는 클립보드 변경을 알려주는 공개 알림이 없기 때문에,
  `NSPasteboard` 의 `changeCount` 를 0.4초마다 확인하는 방식으로 새 복사를 감지합니다.
- **저장 위치**: `~/Library/Application Support/Shelf/`
  - `history.json` — 항목 목록과 텍스트 본문
  - `blobs/<UUID>/<원본 이름>` — 이미지와 파일의 복사본
- **보관 개수**: 고정하지 않은 항목을 최대 50개까지 보관하며, 넘치면 오래된 것부터
  딸린 파일과 함께 지웁니다. 고정한 항목은 이 수에 포함되지 않습니다.
  개수를 바꾸려면 `HistoryStore.maximumItemCount` 값을 고치면 됩니다.
- **큰 파일**: 50MB를 넘는 파일은 복사본을 만들지 않고 원본 위치만 기억합니다.
  원본이 사라지면 그 항목은 더 이상 꺼낼 수 없습니다.
- **민감한 내용 제외**: 비밀번호 관리자 등이 붙이는
  `org.nspasteboard.TransientType` / `ConcealedType` / `AutoGeneratedType` 표식이
  붙어 있으면 아예 읽지 않고 건너뜁니다.

## 소스 구성

| 파일 | 역할 |
| --- | --- |
| `ShelfApp.swift` | 앱 시작 지점. Dock 아이콘 없는 보조 앱으로 설정합니다 |
| `AppDelegate.swift` | 메뉴 바 아이콘, 패널 열고 닫기, 전역 단축키 연결 |
| `ClipboardMonitor.swift` | 클립보드 감시와 종류 판별, 민감 항목 걸러내기 |
| `HistoryStore.swift` | 히스토리 보관, 중복 처리, 개수 제한, 디스크 저장 |
| `ClipboardItem.swift` | 항목 모델 |
| `ShelfPanel.swift` | 포커스를 빼앗지 않는 떠 있는 창 |
| `HistoryView.swift` | 목록 화면 |
| `Localization.swift` | 표시 언어 선택과 문자열 조회 |
| `Preferences.swift` | 가장자리 열기 설정 |
| `EdgeHoverMonitor.swift` | 마우스가 화면 끝에 머물렀는지, 안쪽으로 끌어당겼는지 감지 |
| `EdgePeekPanel.swift` | 화면 끝에 내미는 작은 손잡이 |
| `PanelPresentation.swift` | 창이 자라나고 접히는 움직임 |
| `PanelSelection.swift` | 키보드로 고른 항목 위치 |
| `GlobalHotkey.swift` | 전역 단축키 등록 |

## 아직 만들지 않은 것

- 검색 기능
- 단축키를 앱 안에서 바꾸는 화면 (지금은 `GlobalHotkey` 의 상수를 고쳐야 합니다)
- 한국어와 영어 외의 언어
